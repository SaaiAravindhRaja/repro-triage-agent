# Contributing

This repository is a sandbox for a single-owner assignment. It is not an open
community project and does not accept external pull requests.

## AI contribution policy

The only automated output in this repository is the triage bot, which posts
a bounded comment and applies an existing label on qualifying issues. The bot
does not produce material that humans review and submit; it acts directly and
its output is bounded by the safe-output configuration. There is therefore no
general AI-contribution policy for human contributors.

If you are reviewing this repository for academic purposes, the relevant
policies are in [DESIGN.md](DESIGN.md) (governance controls and AI-use
statement) and [AGENTS.md](AGENTS.md) (forbidden changes and repository
instructions).
